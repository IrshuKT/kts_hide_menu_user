Step 1 — Install

Search & Install from Apps

Find KTS Hide Menu for Users in the Odoo App store. One click to install — no developer mode or configuration files required.

Step 2 — Profile

Create a Menu Profile

Define role-based profiles like "Sales Person" or "Warehouse Staff". Select only the menus that role needs — parent menus are included automatically.

Step 3 — Assign

Assign Profile to User

Open the user form, go to the Menu Access tab and select their profile. One field — that's all it takes. Changes apply on next login or page refresh.
