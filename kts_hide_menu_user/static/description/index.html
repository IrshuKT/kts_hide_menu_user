How It Works

Up and running in 3 steps

01
🔍

Install the Module

Search for KTS Hide Menu in the Odoo Apps store and install it in one click.

02
🗂️

Create a Profile

Go to Settings → Menu Profiles. Create a profile like "Sales Person" and pick which menus they can see.

03
👤
